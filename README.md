# AL-AQSA Website

Static marketing website for AL-AQSA: Mendix consulting, web applications, digital-product delivery and website development.

## Files

- `index.html` — primary marketing website
- `styles.css` — responsive design system and layout
- `script.js` — navigation, animation and prepared email enquiry form
- `privacy.html` — privacy notice
- `assets/al-aqsa-logo.png` — AL-AQSA logo

## Deploy

This project has no build step. Upload the files as-is to any static host, or publish the `main` branch using GitHub Pages. Point `al-aqsa.eu` to the chosen host and keep HTTPS enabled.
